# Project Abstract

## NRB Vidyalaya LMS

**Purpose:** Build a professional, AI-powered Learning Management System for NRB Vidyalaya, a Hindi tuition and language learning institution.

### Problem Statement

Traditional Hindi language education lacks modern digital tools for:
- Interactive learning experiences
- Automated assessment and evaluation
- AI-powered tutoring and conversation practice
- Comprehensive student progress tracking
- Scalable course delivery

### Solution

NRB Vidyalaya LMS provides:
1. **Public Website** - Professional presence with course information
2. **Student Portal** - Self-paced learning, quizzes, assignments, AI tutor
3. **Teacher Portal** - Course management, grading, student tracking
4. **Admin Portal** - Full platform management and analytics
5. **AI Hindi Tutor** - Conversational AI for Hindi practice
6. **AI Question Generator** - Automated quiz creation
7. **AI Writing Correction** - Grammar and writing feedback
8. **MCQ System** - Automatic evaluation and grading

### Technology

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/ui
- **Backend:** Node.js, Express, TypeScript
- **Database:** Supabase PostgreSQL with Row Level Security
- **AI:** OpenAI API (via secure server-side functions)
- **Auth:** Supabase Authentication with role-based access control

### Target Users

- Students learning Hindi (various levels)
- Teachers managing courses and grading
- Administrators overseeing the platform
